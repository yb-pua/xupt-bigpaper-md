# 方向二设计（D0-D6 事实源）

> 单一事实源（2026-08-17 建立）：方向二的实验设计、对比向、论文位置、文献佐证全部在此，不再分散。
> 开题主张（方向二）：设备 DID 关联 SM9 私钥 → KDC 对"设备DID+访问策略"生成 SM9 授权并委托 P2P 中继节点为代理签名者 → P2P 网络分布式组网实现节点发现与拓扑构建 → 代理签名者验证"SM9授权有效性+ST票据合法性+设备DID一致性"，为合法客户端提供通信中继 → SM9 密钥协商生成会话密钥+带特征流量整形安全隧道 → 实现组网准入控制与端到端通信安全结合。
> 铁律：数值对比全部同环境自实现；文献仅方案参照（场景/实现差异显式声明）；呈现用表格/柱状图/曲线，不用圆形图。

## 关键决策（2026-08-17 拍板）

1. **中继=验证型网关**：中继验证 ST/授权/签名链后按 NetPerm 路由转发，**不碰明文**——保留"中继不可解密"主张（不推翻 D5），与方向三 MCP 兼容方案 B+C 复用。
2. **节点发现/拓扑构建=简化方案**：协调服务（controller 兼任）做设备注册/发现（DHT 简化替代）+ 中继邻居表构建星型拓扑；**仅证明可行**，不追求完整 DHT/NAT 穿越。
3. **特征流量整形必做**（开题承诺"带特征流量整形构建安全隧道"），B3 不降级。
4. **指标分层**：连通率/丢包率等为**性能面**参数（功能正确性+代价），与**安全面**参数（拦截率/不可解密/授权粒度）分开呈现。
5. **部署分两阶段**：阶段一本机多进程源码跑通（coordinator 用 subprocess 编排 kdc/relay/device）；阶段二三方向完成后 Docker+Web 联调（2026-08-17 决策）。

## D0 组网基础设施（节点发现+拓扑构建）

- **实验**：协调服务设备注册/公告 + find_node 查询（DHT 简化替代）；中继维护邻居表构建星型拓扑；新设备"发现→入网→与已准入设备通信"全链路可行性证明。
- **简化声明（论文口径）**：以集中信令替代 DHT 实现节点发现，拓扑为星型；证明"分布式组网技术可支撑票据化准入"即可；NAT 穿越列为真实部署扩展项（论文说明）。
- **对比向**：内部机制验证（可行性）+ 方案引文（[17] TUN P2PVPN、[22] 国密 P2P VPN 的 DHT/信令参照）。
- **论文位置**：4.2（组网与拓扑）+ 4.5（实验）。

## D1 票据化准入有效拦截（实验 B1+B4）

- **实验**：6 类节点（合法/过期/重放/伪造/篡改/冒用）分类正确率（应 100%）；B4 七用例拦截率；与"无票据 P2PVPN"基线同用例拦截率对比（安全差距证据）。
- **对比向**：数值自实现（同环境无票据基线）；方案引文（[22][51] 现状参照）。
- **论文位置**：4.3（方案）+ 4.5（实验）+ 第6章安全属性矩阵。

## D2 授权委托安全（代理签名）

- **实验**：KDC 生成授权 A={DID_dev, policy, exp, Sig} + 代理签名密钥分发中继；中继代理验签；**伪造能力测试**（中继无 KDC 主密钥，无法伪造新授权/越权授权）。
- **对比向**：内部机制验证（伪造测试）；方案引文（SM9 高级原语 [12][13][14][15]；SM9 代理签名待检索）。
- **论文位置**：4.3（方案）+ 4.5（实验）。

## D3 票据化开销（实验 B1 时延 + B2）

- **实验**：准入时延三段分解（授权验签/ST 校验/挑战应答，p50/p90）+ vs 无票据基线增量；随 N 扩展。
- **对比向**：数值自实现（同环境无票据基线）。
- **论文位置**：4.5（实验，Q2）。

## D4 去中心化增益（实验 B2）

- **实验**：N=10/50/100/200 扩展性曲线（准入时延/聚合吞吐/e2e 时延/丢包）；vs OpenVPN 网关同环境；**故障注入**（kill 中继 vs kill 网关 → 中断范围/恢复时间）。
- **对比向**：数值自实现（同环境 OpenVPN）。
- **论文位置**：4.5（实验，Q3）+ 第6章综合。

## D5 SM9 密钥协商隧道（实验握手/吞吐 + B4-4）

- **实验**：SM9 密钥协商握手轮次/时延、隧道吞吐、中继侧仅见密文（B4-4 恶意中继）；vs IPsec/TLS 基线（同环境）。
- **对比向**：数值自实现（IPsec/TLS 自实现基线）+ 方案引文（中继不可解密 vs TLS 网关终止，定性）。
- **论文位置**：4.4（方案）+ 4.5（实验）。

## D6 特征流量整形（实验 B3）

- **实验**：三型业务流（周期/突发/交互）整形前后包长/间隔分布、分布熵 H、与均匀参考分布 KL 散度、带宽冗余率（≤15%）、时延增量。
- **对比向**：内部参数（整形前后自对比）；方案引文（[29] 隐蔽通信、[32] 匿名追踪、Tor/pluggable transports 待补库）。
- **论文位置**：4.4（方案）+ 4.5（实验，Q4）。
