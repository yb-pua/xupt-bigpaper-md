> 主成果：CN121567387A《基于SM9与生物特征模糊提取的Kerberos身份认证系统及认证方法》（申请号 CN202511687563.7A，2025-11-18 申请，2026-02-24 公开）。

## 0. 专利主成果结构速览（论文必须以它为准）

**四大模块**：
1. 生物特征密钥生成模块：采集（dlib 人脸 128 维，10 张）→ Min-Max 归一化 → 稳定比特提取（众数投票+稳定性评分，阈值 0.8）→ 密钥生成（SHA-256→256bit bio_key）+ RS 纠错码辅助数据（n=255,k=191,t=32 字节）
2. SM9 数字身份管理模块：DID 生成（`didsm9:<user_id>:<hash>`，SHA-256+BLAKE2b 64 字节，冲突自动重试）→ KGC（TEE 内）基于 DID 派生 SM9 私钥 → 身份凭证文件（JSON：user_id/DID/key_hash/sk_s/mpk_s，存 TEE）
3. Kerberos 协议增强模块：注册（SM9 签名 user_id+DID+时间戳）→ AS-REQ 前置 SM9 验签（替代口令哈希验证）→ 验签通过后走标准 TGT→TGS→ST 流程（**保留标准票据格式与加密模式，完全兼容现有 Kerberos**）；时间戳新鲜性 30 分钟（NTP 同步）
4. 安全熔断与管理模块：行为监控（实时审计日志）→ 熔断决策（连续失败阈值，3 次）→ is_blocked 标记 + 删除会话/票据 → 恢复单元（强制完整重注册，重建身份绑定）

**主张效果**：抗票据伪造与重放（30min 时间戳）、解决静态密钥泄露（动态生物密钥、非存储式）、生物特征隐私（只存辅助数据+key_hash，模板即弃）。

## 2. 连带影响（次生修改）

1. **G3 差距清单更新**：原"重复码/BCH 可切换"→ 主构造改为 RS(255,191,t=32)，重复码/BCH 为对比实验（纠错码对比小节）；
2. **实验 A1 参数对齐**：阈值扫描、KRR/FAR/FRR 计算基于 RS 纠错参数；
3. **A5 攻击用例扩展**：新增暴力破解熔断用例（连续失败计数、阈值触发、恢复流程验证）；
4. **A4 性能对比**：基线"国密算法替换版 Kerberos"表述与专利"保留标准票据格式兼容"一致（对比口径=认证入口差异，票据链路同源）；
5. **方向二/三衔接**：专利第7步服务访问（REST API + 票据头）可作为方向三 MCP 服务端验证的入口接口；方向二 ST 票据扩展（NetPerm 等）在论文中须注明"在保留标准格式兼容前提下扩展字段"。

## 4. 建议（一次性给全）

- 论文**技术细节一律以专利为准**（RS 码、didsm9、0.8 阈值、30min、TEE、熔断），实验体系在专利框架内扩展；
- 实验侧保留 InsightFace（D1-A）与安全模板扩展（D2-A），作为"专利未覆盖的学术完整性"表述为"扩展研究"；
- 新增熔断实验是论文相对专利的"验证补齐"亮点——专利有机制无实验，你补实验正好形成"机制+实测"闭环；
- 哈希函数建议 D3-A（与主成果一致 + 注明 SM3 可替换），国密合规性在论文中通过 SM9/SM4/SM3 体系论述。
