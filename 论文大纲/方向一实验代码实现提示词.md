## 2. 技术约束（与专利一致，不可偏离）

| 项 | 实现 |
|---|---|
| 特征提取 | InsightFace buffalo_l 512 维（主）；dlib 128 维（投票消融对照）；可切换 |
| 预处理 | Min-Max 归一化到 [0,1]（专利公式） |
| 稳定比特 | 多数投票（众数）+ 稳定性评分，阈值 **0.8** |
| 密钥 | bio_key = **SM3**(稳定序列) → 256 bit |
| 纠错码 | **RS(255,191,t=32 字节)**（reedsolo）；重复码为投票消融参考 |
| 存储 | 只存 σ + key_hash=SM3(bio_key)；σ 不含明文特征（非存储式） |
| DID | `didsm9:<user_id>:<SM3 哈希>`，冲突重试 |
| KGC | 基于 DID 派生 SM9 私钥；KGC 运行于**模拟 TEE**（独立进程+主密钥不进日志+派生审计）；无 SGX 标注"模拟 TEE" |
| SM9 | **gmalg 单库**（SM9/SM3/SM4 全用；gmssl 不需要——其 Python 版不支持 SM9）；gmalg 某接口不可用→模拟实现并标注"SM9 模拟" |
| 票据 | 注册（SM9 签名 ID+DID+ts）→ AS-REQ 前置验签替代口令 → TGT→TGS→ST；**时间戳窗口 30min**；票据载荷 **SM4**（保留标准票据格式）；字段含 **ticket_id** |
| 熔断 | 连续失败 **3 次** → is_blocked → 删除会话与票据 → **L1 恢复（Rep 重认证，bio_key/DID 不变）**；L1 失败才 L2 重注册（重新 Gen+显式更新登记） |
| 哈希 | 全链路 **SM3**（bio_key/key_hash/DID/完整性），禁止 SHA-256/BLAKE2b |
| 随机 | 全局固定 SEED（README 记录） |
| 匿名 | 代码/注释/README 不得出现作者/学校等身份信息 |

## 5. 实验（experiments/，独立可跑 + run_all 汇总）

### A1 密钥可恢复
- 输入：5 张档 423 人（单张 vs 5 张投票消融）；跨条件双样本 1680 人；异人 ≥5000 对
- 流程：录入（Gen）→ 验证（Rep）→ **Hamming 距离接受阈值 θ 扫描**（0→超纠错能力，出 KRR/FAR_key/FRR_key/AUC/EER）
- 输出：`expA1_threshold_scan.csv`（theta, krr, far_key, frr_key）、`expA1_vote_gain.csv`（mode, n_persons, stable_ratio, krr）、`expA1_summary.csv`（eer, auc, krr）

### A2 噪声鲁棒
- 输入：同人样本；**图片级**五类扰动 × 强度梯度
- 流程：注册侧加噪→Gen；认证侧加噪→Rep（恢复率随强度）
- 输出：`expA2_noise_robustness.csv`（noise_type, intensity, krr）、`expA2_cross_condition_anchor.csv`（跨条件等效噪声点）

### A3 端到端认证
- 流程：注册→AS→TGS→AP 全流程；异常路径（过期/错生物特征/篡改）；**熔断路径（3 次失败→L1 恢复→断言 bio_key/DID/票据链不变）**
- 输出：`expA3_e2e_results.csv`（success, stage_latency）、`expA3_stage_latency.csv`

### A4 性能对比
- 基线（同环境自实现）：Password-Kerberos / SM2-PKINIT / 本文 SM9；**RSA-PKINIT 待定**（数据差距过大可不实现）
- 指标：AS-REQ 全流程时延 p50/p90、阶段分解、消息尺寸、成功率
- 输出：`expA4_performance.csv`、`expA4_message_sizes.csv`

### A5 攻击面+隐私
| 用例 | 动作 | 预期 |
|---|---|---|
| A5-1 重放 | 过期 ts/重复 nonce 重发 | 拒绝（拦截率） |
| A5-2 伪造 | 篡改 M 不重签/伪造票据 | 验签失败 |
| A5-3 冒用 | 他人 DID 绑定伪造 | 绑定校验失败 |
| A5-4 泄露 | 仅持 σ+key_hash 恢复特征/密钥 | 成功率≈0 |
| A5-5 暴力破解 | 连续错误→熔断 L1/L2 | 熔断触发率、L1 成功率、L2 兜底率 |
| A5-6 隐私 | σ 与特征互信息估计、模板撤销（重注册后旧凭据失效） | 互信息低、撤销生效 |
- 输出：`expA5_attack_results.csv`（attack_type, attempts, blocked, block_rate）、`expA5_privacy.csv`（mutual_info, leak_recovery_rate, revoke_ok）

## 7. 验收（全过才算完成）

1. `run_all.py` 从空 results 一键复现全部 CSV；
2. 抽查 3 组 CSV 数值与代码逻辑一致；
3. RS 自测：≤32 字节错 100% 恢复，>32 失败（或误纠错被 key_hash 拦截）；
4. 熔断自测：3 次失败→L1 恢复（bio_key/DID 不变）；L2 触发时显式更新登记；
5. 超 30min 请求 100% 拒绝；
6. 预留接口单测：verify_chain（≥2 签名顺序校验）、key_exchange（双方会话密钥相等）、proxy_verify（篡改策略 False）、verify_ticket（claims_checker 被调用）；
7. 匿名检查：`grep -rn "姓名\|学校\|学院" core/ experiments/ README.md` 零命中；
8. 专利常量可查：0.8 / 30min / 3 次 / RS(255,191,t=32) / didsm9 / SM3。
