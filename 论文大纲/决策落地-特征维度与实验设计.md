## 1. 特征维度：128 vs 512（计算量分析与定位）

**计算量分解**（对密钥生成全链路）：

| 阶段 | 128 维 (dlib) | 512 维 (InsightFace) | 差异 |
|---|---|---|---|
| 特征提取（backbone） | ResNet-29 级，~40MB，CPU 几十 ms/张 | ResNet100 级，数百 MB，GPU 几 ms/张 | **主要差异源（约 10-20 倍参数）** |
| 归一化/投票/稳定性评分 | 128 bit 候选 | 512 bit 候选 | 线性，微秒级 |
| RS 编码（255,191,t=32） | 相同（256bit bio_key → 32B 信息位） | 相同 | 无差异 |
| SM3/DID 哈希 | 相同 | 相同 | 无差异 |
| SM9 签名/验签 | 相同 | 相同 | 无差异 |

**结论**：
- 维度本身不构成瓶颈（后续全是微秒级），瓶颈在特征提取模型；
- 128 维 dlib 适合"实时采集+资源受限"部署；512 维 InsightFace 精度更高（LFW 上 FAR/FRR 更好）；
- **定位**：论文实验主配置 = InsightFace 512 维（指标质量优先）；方案叙述保留"特征提取器可替换（专利实施例 dlib 128 维）"；新增**特征维度对比实验**（128 vs 512：提取耗时 + EER/恢复率），弥合专利实施例与实验配置差异，并支撑"轻量部署可选 128 维"的结论。

**需求清单修改**：1.1 追加"特征维度对比实验（128 vs 512）"，输出 `expA1_dim_compare.csv`（model, dim, extract_ms, eer, krr）。

## 2. LFW 双样本实验设计（一张录入 + 一张验证 + 偏移模拟）

**数据**：LFW 中 ≥2 张照片的人 ≥300 人（库内约 1680 人满足）；每人对：A 图=录入，B 图=验证；异人随机配对 ≥5000 对测 FAR。

**流程**：
```
录入：A 图 → 特征 → 扰动副本 K 份（高斯噪声/亮度偏移/仿射）→ 投票 → 稳定比特(阈值0.8) → RS 辅助数据 σ + key_hash
验证：B 图（真实跨条件样本）→ 特征 → 扰动副本 → 稳定比特 → Rep(σ) → 恢复 → key_hash 比对
攻击：随机他人特征 → Rep → 应失败（FAR）
```

**指标**（分开报告）：
- KRR_真实（B 图跨条件恢复率）——含真实拍摄条件噪声，更有说服力；
- KRR_扰动（A 图+扰动同源恢复率）——验证纠错能力上限；
- FAR/FRR/EER（结合异人配对 + 阈值扫描）。

**注意**：跨条件差异可能超过 RS 纠错上限（t=32 字节），先做 30 人预试验定恢复率基线；若 KRR_真实 偏低，论文如实报告并讨论"跨条件噪声 vs 纠错能力"的权衡（RS 参数可调）。

**需求清单修改**：1.9（A1）输入改为上述双样本设计；1.7 投票数据来源同步更新。

## 3. 安全模板：专利未使用 → 保留为对比方向

**事实核对**：专利全文无私密模板/可撤销模板技术（隐私保护靠"非存储式"：只存辅助数据 σ + key_hash，模板即弃）。

**论文定位**：主方案=非存储式（专利）；对比方向=安全模板路线（BioHashing：随机投影变换+存储变换后模板）。

**对比实验设计**（exp5/exp6 改造）：
| 维度 | 非存储式（主方案） | 安全模板（对比） |
|---|---|---|
| 存储内容 | 辅助数据 σ + key_hash | 变换后模板（随机投影） |
| 不可逆性 | σ 不含特征信息（形式化论证） | 投影变换不可逆（需论证） |
| 可撤销 | 不适用（无模板可撤） | 更换投影密钥即撤销（exp6） |
| 精度 | 主指标 | 变换前后 EER 保持（exp5） |
| 隐私攻击面 | 最小（无模板可窃取） | 模板泄露风险（预映像攻击） |

**论文意义**：该对比回答"为什么不存模板"——非存储式的隐私收益（无模板可窃）vs 安全模板的可撤销灵活性，成为论文相对专利的补充讨论点。

## 4. 全链路国密化（SM3/SM4）

**修改**：
- bio_key = **SM3**(稳定序列) → 256 bit（专利为 SHA-256，替换为国密 SM3）；
- key_hash = **SM3**(bio_key)；
- DID 哈希 = **SM3**（`didsm9:<user_id>:<SM3 32字节>`，专利 BLAKE2b 64 字节→SM3 32 字节，256bit 抗碰撞足够）；
- 票据加密（TGT/ST 载荷）由 AES 改 **SM4**；
- 时间戳/随机数不变（NTP + 密码学随机数）。

**兼容性表述调整**：专利"保留标准票据格式与加密模式"→ 论文改为"**保留标准票据格式、加密算法国密化**（SM4 替换 AES）"；完全兼容现有 Kerberos 的卖点降级为"格式兼容"，避免与国密化冲突。

**全链路国密套件清单**（论文统一表述）：
| 用途 | 算法 |
|---|---|
| 数字签名/密钥协商 | SM9（GB/T 38635） |
| 哈希（密钥生成/DID/完整性） | SM3（GB/T 32905） |
| 对称加密（票据载荷/会话） | SM4（GB/T 32907） |
| 随机数 | 密码学安全随机数（GM/T 0005） |

**连带**：方向二（ST 票据/隧道 SM4）与方向三（签名链 SM9+SM3）全篇算法统一，论文"国密合规"表述更彻底。
