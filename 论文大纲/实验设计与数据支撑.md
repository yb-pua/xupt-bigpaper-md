# 实验设计与数据支撑说明

> 配套文档：《学位论文完整版.md》第6章。本文档面向开题/答辩，聚焦"实验怎么设计、需要什么数据"两个问题，给出可执行清单。

---

## 1. 实验目标与总体思路

三个研究方案分别回答三个问题，实验须分别证明其有效性：

| 方案 | 核心主张 | 实验要证明的命题 |
|---|---|---|
| 方案一（SM9+生物模糊提取+Kerberos） | 生物密钥可稳定再生、可驱动 SM9 认证、可阻断伪造/重放 | P1: 含噪生物特征下密钥再生成功率足够高（FRR 低）；P2: 伪造者无法通过认证（FAR 低）；P3: 认证时延增量可接受 |
| 方案二（ST票据+P2PVPN） | 票据化准入可拦截非法节点、支持细粒度授权、隧道端到端保密 | P4: 三重验证可拦截重放/伪造/冒用；P5: 组网规模扩展性良好；P6: 流量整形隐藏特征且开销可控 |
| 方案三（双DID+签名链+MCP） | 指令级权限管控可检出篡改/越权/重放 | P7: 签名链验证正确率≈100%；P8: 验证开销相对 OAuth 可接受；P9: 安全属性矩阵优于基线 |

总体原则：**每条结论必须有对应实验数据**；公开数据集为主、自采/合成数据为辅并在文中标注来源；攻击用例以"注入—检测"方式量化拦截率。

## 3. 数据需求清单

### 3.1 生物特征数据（方案一核心数据）

| 数据 | 规模建议 | 来源 | 获取方式 | 格式/预处理 |
|---|---|---|---|---|
| FVC2004 指纹（DB1-DB4） | 每库 80 指 ×8 采样 | 公开（FVC onGoing） | 官网下载 | 灰度图 → 细节点/纹理特征 → 256bit 二进制串 |
| FVC2006 指纹 | 每指 12 采样 | 公开 | 官网下载 | 同上（用于跨库验证） |
| CASIA-Iris-Thousand | 1000 类×采样 | 中科院模式识别实验室公开库 | 官网申请 | 虹膜归一化 → 相位/纹理编码 |
| 实验室自采（指纹/人脸） | ≥30 人 ×10 次 | 实验室设备（指纹仪/摄像头） | 自主采集 | 需伦理审查与知情同意 |

**关键设计点**：①每次采样→同一特征提取流水线→固定长度比特串，保证 w 与 w′ 同分布；②同用户多采样用于多数投票（n=4,6,8,10,12 五档作自变量）；③不同用户样本对用于 FAR 统计（如 80 指中任取两不同指的再生成功率）。

| 数据 | 规模 | 来源 | 说明 |

## 4. 指标定义

- **误拒绝率 FRR** = 同用户不同采样的密钥再生失败数 / 同用户配对总数
- **误接受率 FAR** = 不同用户采样的密钥再生"成功"数 / 异用户配对总数（等价随机再生成功率）
- **EER**：FAR=FRR 时的参数点
- **稳定比特比例** = 投票一致率 ≥θ 的比特数 / 总比特数（自变量 n 的函数）
- **密钥再生成成功率** = 1 − FRR
- **认证时延** = 客户端发出 AS-REQ 至收到 TGT 的耗时（本地域与跨网两场景）
- **准入时延** = 设备提交入网请求至获得虚拟地址的耗时（中位数/90 分位）
- **聚合吞吐** = 全网单位时间成功转发业务字节数（N 节点满配测试）
- **带宽冗余率** = (整形后流量 − 原始流量) / 原始流量
- **篡改检出率 / 越权拒绝率 / 重放拒绝率** = 对应攻击用例被拒绝数 / 攻击用例总数
- **QPS** = 并发场景下 MCP 网关单位时间处理请求数

## 5. 对比基线

| 实验 | 基线方案 | 对比指标 |
|---|---|---|
| 1-2 | 标准口令 Kerberos（AES 套件）、国密算法替换版 Kerberos[21] | 认证时延、抗离线破解能力 |
| 2-2/2-3 | 无票据 P2PVPN（静态密钥）、中心化 OpenVPN 网关 | 准入时延、吞吐、扩展性、授权粒度 |
| 3-2/3-4 | OAuth 2.1（授权码+PKCE）直连 MCP | 验证时延、权限粒度、安全属性矩阵 |

## 7. 数据采集合规与风险

1. **生物数据伦理**：公开数据集按各自授权条款使用；自采数据须经实验室伦理审查、知情同意，脱敏存储，仅用于实验不进入论文附件。
2. **数据不足风险**：优先权威公开库；合成数据（MCP 指令集、权限矩阵）明确标注，避免误导。
3. **TEE 依赖**：若硬件 SGX 不可用，先用软件模拟验证协议正确性，TEE 硬件实验列为增强项。
4. **性能结论可信度**：每组实验重复 ≥10 次取中位数，报告标准差；注明硬件平台与库版本，保证可复现。

## 8. 结论（实验设计的回答）

**怎么设计**：按"功能正确性 → 性能与扩展性 → 安全对抗 → 对比基线"四层递进组织；每个方案至少 3 个实验，形成"指标—数据—结论"一一对应链（第2节矩阵）。

**需要什么数据**：①生物特征公开库（FVC2004/2006、CASIA-Iris）+ 自采；②网络拓扑与业务流数据（NS-3+实验室平台）；③MCP 权限矩阵与四类指令集（自建合成）；④OAuth 基线数据（同环境实测）；⑤密码运算时延数据（GmSSL/自研 SM9，双平台）。全部数据来源在论文中标注，保证可复现与学术诚信。
