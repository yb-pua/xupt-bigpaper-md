## 与代码库的协作约定

- 规范变更先改本库 `代码汇总版.md`，再改实验代码，最后提交对应方向库；
- 实验产出 CSV 只进实验库 `results/`，本库不含任何代码与数据；
- 论文取数统一引用实验库 RUN.md 的数据接口表。
