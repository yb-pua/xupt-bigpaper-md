## 专利关键技术要点（实现对照）

- **非存储式生物模板**：只存辅助数据 σ（码字⊕W_ext），不存明文特征；Gen 注入随机盐使重登记 σ 不可链接。
- **稳定比特提取**：多数投票 + 稳定性阈值 0.8 → 256 位稳定序列 W。
- **模糊提取器**：`bio_key = SM3(W)`；RS(255,191,t=32) 纠错码，`max_correct` 预留异人安全边际。
- **SM9 前置验签替代口令**：AS 注册/认证以生物密钥派生私钥签名，替代传统口令哈希。
- **票据安全**：SM4-CBC 密封、30min 时间窗、nonce 防重放、ticket_id 全链审计。
- **模拟 TEE**：多进程隔离持有 KGC 主密钥，审计日志不含主密钥材料。
- **安全熔断**：连续 3 次失败 → L1 票据清理 + Rep 重认证；L1 失败 → L2 重新 Gen + 更新登记。
